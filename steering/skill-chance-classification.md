# 技術性與機率性分類指引

魚機顧問工作的第一個問題不是「RTP 設多少」，而是「這台機器在目標市場的法律上是什麼」。同一份程式碼在不同司法管轄區可能是合法娛樂機具、需牌照的賭博機具，或是查扣即刑事案件的違法裝置。這份指引處理那個判定。

**本指引提供技術合規分析，不是法律意見。** 分類結論具刑事後果，最終判定必須由目標市場的執業律師出具。本指引的作用是讓您在找律師之前，知道要問什麼、要準備什麼證據。

---

## 1. 為什麼魚機的分類問題比老虎機嚴重

老虎機沒有分類爭議：玩家按下按鈕，結果由 RNG 決定，全世界都同意它是機率遊戲。魚機不同——玩家做了大量看起來有意義的決定：

| 玩家決策 | 是否影響期望值 |
|----------|----------------|
| 瞄準角度與提前量 | 可能影響（若命中判定含幾何運算） |
| 砲倍選擇 | 影響單發成本與潛在報酬，通常不影響 RTP 比率 |
| 目標魚種選擇 | 可能影響（不同魚種的期望報酬率若不相等） |
| 發射時機與節奏 | 通常不影響 |
| 道具使用時機（雷射／冰凍／鎖定） | 可能影響 |
| 何時離桌 | 不影響長期 RTP，影響個人結果變異 |

正是這些決策讓廠商主張「我們是技術遊戲」。而監管機關與法院關心的是：**扣掉這些決策，機率還剩多少決定力**。

## 2. 三種法律測試（美國各州）

美國各州對「技術 vs 機率」採用不同測試，結論可能完全相反。判斷目標州採用哪一種，是分析的起點。

### 2.1 Predominant factor test（優勢因素測試，又稱 dominant element test）

多數州採用。問題是：**技術是否勝過機率決定結果**。若知識、熟練度、練習對勝負貢獻更大，則屬技術遊戲。

對魚機的意義：這是廠商唯一有機會通過的測試，但必須拿出量化證據（見第 5 節）。

**關鍵警示：** 北卡羅來納州最高法院在 *Gift Surplus, LLC v. State ex rel. Cooper*（2022）就一款強調技術操作的機台，認定**機率成分優於技術成分**，因而屬州法禁止的機率性視訊遊戲。這是魚機類產品在採用優勢因素測試的州仍然敗訴的實例。不要假設「有操作 = 通過測試」。
- 判決來源：https://www.nccourts.gov/documents/appellate-court-opinions/gift-surplus-llc-v-state-ex-rel-cooper

### 2.2 Material element test（實質要素測試）

部分州採用。問題是：**機率是否以任何實質程度存在**。門檻遠低於優勢因素測試。

對魚機的意義：幾乎必然失敗。魚機的捕獲判定本身就是機率抽樣，這在任何合理解讀下都是實質要素。若目標州採用此測試，「技術遊戲」路線應視為不可行，改走持照路線或放棄該市場。

### 2.3 Any-chance test（任何機率測試）

最嚴格。只要存在任何機率成分即屬博彩。

對魚機的意義：不可能通過。

### 2.4 判定流程

```
1. 確認目標州採用哪種測試（需當地律師確認，勿依產業文章）
2. 若為 any-chance 或 material element → 技術遊戲路線不可行
3. 若為 predominant factor → 進入第 5 節的量化舉證，且預設會被挑戰
4. 無論結論為何，同時評估持照路線與不進入該市場的選項
```

賓州的訴訟脈絡顯示這個問題在州內仍在演變：*In re: Three Pennsylvania Skill Amusement Devices* 的下級法院採用優勢因素測試，認定未持照營運不受 Crimes Code §5513(a) 禁止，該爭點後續上到州最高法院。市場狀態可能在專案週期內改變，必須設定法規追蹤（見 `change-management-recert.md`）。
- 來源：https://law.justia.com/cases/pennsylvania/supreme-court/2026/50-map-2024.html

## 3. 英國：測試邏輯完全不同，且結論明確

英國不使用優勢因素測試。UK Gambling Commission 對「Skill With Prizes（SWP）」與「gaming machine」界線的官方指引明確表示：

1. **只要遊戲結果可以被機率影響，即為 Gambling Act 2005 意義下的 game of chance。**
2. **機率成分是否大於技術成分，不影響此認定。**
3. **機率成分能否被高超技術消除，也不影響此認定。**
4. **一組技術遊戲中只要有一款屬機率遊戲，整台機器即被歸類為 gaming machine。**

指引另列出即使遊戲本身不含機率，仍可能因「呈現上像賭博」而被認定的判準：遊戲外觀、名稱是否使用 `stake`、`jackpot` 等博彩語彙、機殼與畫面是否含博彩符號（BAR、鈴、幸運 7、水果、轉盤、骰子、捲軸帶、隨機選號）、玩家動作是否類似下注、以及廣告與招牌等情境線索。

**對魚機的直接後果：**

| 設計 | 英國分類後果 |
|------|--------------|
| 捕獲成功與否含任何隨機抽樣 | game of chance → gaming machine |
| 機台上另有一款拉霸小遊戲 | 整台機器成為 gaming machine |
| 畫面顯示「JACKPOT」「BET」字樣 | 即使純技術也可能被認定為呈現上像賭博 |
| 魚種賠率以「×100」「×300」倍數呈現 | 需評估是否構成博彩語彙／呈現 |

英國魚機幾乎必然是 gaming machine，接著受 A–D 類的投注與獎金上限、可設置場所與年齡限制拘束。C 類限 18 歲以上、投注上限 £1、獎金上限 £100；D 類無年齡限制但限額更低。把魚機定位為家庭娛樂中心（FEC）機台的商業誘因，代價是極低的投注與獎金上限，通常使原本的數學模型完全不成立。
- SWP 指引：https://www.gamblingcommission.gov.uk/licensees-and-businesses/guide/skill-with-prizes-swps
- 機器分類：https://www.gamblingcommission.gov.uk/licensees-and-businesses/guide/gaming-machine-categories
- 法源 §6：https://www.legislation.gov.uk/ukpga/2005/19/section/6

## 4. 台灣：分類由行政評鑑決定，且「不得有賭博設計」是硬條件

台灣的機制不是法律測試，而是**事前行政評鑑**。依電子遊戲場業管理條例：

- 第 4 條：電子遊戲機**不得有賭博或妨害風化之設計及裝置**；分類為益智類、鋼珠類、娛樂類，分類標準由經濟部定之。
- 第 5 條：營業分級為普通級（僅益智類，可供兒童少年）與限制級（鋼珠類、娛樂類，僅供 18 歲以上）。同一營業場所不得混合營業級別。
- 第 6 條：製造業、進口人或軟體設計廠商應於製造或進口前，就其**軟體**申請核發評鑑分類文件；出廠或進口時申請查驗，合格者發給機具類別標示證。**專供出口之製造不在此限。**
- 第 14 條：限制級每次兌換或取得獎品價值不得超過新臺幣 2,000 元，普通級不得超過 1,000 元；**禁止以現金、有價證券或其他通貨為獎品，禁止買回提供給客人的獎品**；獎品價值以業者原始進貨發票為依據。
- 第 17 條第 1 項第 5 款：不得在機台使用真幣、信用卡、金融卡、現金卡、儲值卡或其他作為簽帳、提款、轉帳或支付之電磁紀錄物或晶片；娛樂用代幣之大小、式樣或重量不得與真幣相同或近似。
- 第 17 條第 1 項第 6 款：不得有涉及賭博、妨害風化或其他犯罪行為。

法源全文：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0080024

**工程含義：**

1. 台灣內銷魚機的兌現層必須是**獎品／彩票**，不能是現金，且單次兌換價值受上限拘束。「買回獎品」是明確禁止的規避手法。
2. 機台不得接受真幣或任何支付性卡片，代幣規格受限。這直接約束硬體選型，見 `cabinet-hardware-compliance.md`。
3. 評鑑分類針對**軟體**，因此數學模型與判定邏輯就是送審對象，不是附件。
4. 專供出口的製造免評鑑，這是台灣成為魚機製造與出口重鎮的制度原因。但**出口免評鑑不代表目的地市場合法**，這是本指引最常需要糾正的誤解。

## 5. 技術貢獻度的量化舉證

若要在採用優勢因素測試的市場主張技術性，行銷話術沒有用。需要可重現的量化證據。

### 5.1 需要產出的數據

| 指標 | 定義 | 用途 |
|------|------|------|
| RTP<sub>random</sub> | 隨機瞄準、隨機目標選擇、不使用道具的策略下的長期 RTP | 技術下界 |
| RTP<sub>optimal</sub> | 已知最佳策略（最佳目標選擇與道具時機）下的長期 RTP | 技術上界 |
| 技術跨距 | RTP<sub>optimal</sub> − RTP<sub>random</sub> | 技術可影響的期望值幅度 |
| 命中率跨距 | 熟練玩家與隨機瞄準的實際命中率差 | 操作技術的可測量性 |
| 學習曲線 | 相同玩家在 N 小時後的 RTP 變化 | 證明「練習有用」 |
| 玩家間變異分解 | 結果變異中歸因於策略 vs 歸因於機率的比例 | 優勢因素測試的核心數字 |

### 5.2 判讀

- 技術跨距若只有 1–2 個百分點，實務上主張「技術優於機率」極為薄弱。
- 若最佳策略與隨機策略的 RTP 幾乎相同，那麼設計上玩家的操作根本不影響期望值，此時技術性主張在事實層面就不成立，無論法律測試為何。
- 若技術跨距很大（例如 15 個百分點以上），則反而要注意另一個風險：**熟練玩家可能把 RTP 推到 100% 以上**，這是營運風險而非合規風險，但同樣需要在數學驗證中處理。見 `math-verification.md` 的技術水準敏感度分析。

### 5.3 分類舉證卷宗

以 `templates/certification/skill-chance-dossier.json` 建立卷宗，內容包含：設計上的技術影響點清單、每個影響點對期望值的量化貢獻、模擬方法與樣本量、不同技術水準的 RTP 分佈、以及呈現層是否含博彩語彙的自我檢查。這份文件同時是律師意見書的事實基礎與送測時的說明材料。

## 6. 兌現模式如何改變分類

分類不只看遊戲機制，也看價值流。相同的遊戲程式在不同兌現模式下分類可能不同。

| 兌現模式 | 一般分類傾向 | 主要風險 |
|----------|--------------|----------|
| 現金投入、現金取回 | 幾乎必然是賭博 | 無牌即刑事 |
| 現金投入、獎品／彩票兌換 | 依市場而定；台灣有明文上限與禁止買回 | 「買回獎品」與獎品換現金的實質認定 |
| 現金投入、不可兌回 | 通常為娛樂機具 | 若場所私下兌現，責任可能上溯供應商 |
| 虛擬幣、不可兌回 | 通常非博彩 | 第三方帳號交易市場可能使「不可兌回」不成立 |
| Sweepstakes 模式 | 高度爭議 | *Gift Surplus* 型判決的主要打擊對象 |

「不可兌回」不是宣告就成立的事實，而是需要用系統設計與場所稽核維持的狀態。若您的產品把兌現責任推給場所業者，責任邊界必須在合約與技術上都明確，見 `advisory-engagement.md`。

## 7. 顧問對話流程

當開發者問「我們的魚機算技術遊戲嗎」：

1. **先問市場。** 沒有市場就沒有答案，英國與採用優勢因素測試的美國州份結論相反。
2. **再問兌現模式。** 這決定分類分析的整個框架。
3. **檢查呈現層。** 即使機制上是技術遊戲，英國式的「呈現上像賭博」判準可能直接翻盤。魚機常見的高倍數顯示、金幣特效、JACKPOT 字樣都是風險點。
4. **量化技術貢獻。** 若無法量化，就告訴對方目前沒有可主張的立場。
5. **明確劃出法律意見的邊界。** 提供事實與分析，不提供結論性法律意見。
6. **同時提出持照路線。** 技術遊戲路線失敗時的替代方案應該一開始就在桌上，而不是被查扣之後才討論。

## 8. 需要主動說出的事

即使開發者沒問，以下事項應主動提出：

1. **出口免評鑑不等於目的地合法。** 台灣的專供出口豁免只免除台灣的評鑑義務。
2. **「有技術成分」不是通行證。** *Gift Surplus* 就是強調技術操作仍被認定為機率遊戲的案例。
3. **一台機器只要有一款機率遊戲，在英國就整台變成 gaming machine。** 常見的「主遊戲是魚機、附一個小拉霸」設計會直接觸發。
4. **美國多州已將 fish table 明文視為執法目標。** 夏威夷 2026 會期的 SB3281 在立法理由中直接點名 fish games／fish tables／fishing games；佛州 2025 年多次執法行動將 fish tables 與違法拉霸機並列查扣。這些市場沒有「換個說法就能上架」的空間。
5. **分類結論會過期。** 賓州的訴訟顯示同一市場的狀態會在專案週期內改變。
